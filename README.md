# Movie Database System

A Java-based Movie Database System developed as part of my Data Structures & Algorithms coursework.

The project applies different data structures to efficiently store, organise and retrieve movie-related data.

## Data Structures Used

- Arrays
- Linked Lists
- Stacks
- Queues
- Hash Tables
- Binary Search Trees
- AVL Trees
- Heaps
- Graphs

## Technologies

- Java
